常见问题

软件需要什么环境？

Windows 10/11 即可，无需安装 Python 或任何依赖。解压后双击 exe 就能用。

截图会被上传吗？

不会。软件完全本地运行，不联网，截图只在你自己电脑上处理和保存。

长截图支持哪些窗口？

需要窗口自身支持滚动，浏览器、Word、记事本都可以。如果窗口内容固定不变，程序会自动识别并停止。

马赛克能把敏感信息彻底遮住吗？

马赛克是像素化，不是加密。要绝对安全请用专门的打码工具或直接遮挡。

GIF 录屏文件太大怎么办？

调低帧率（4 帧/秒）、缩短时长，或只录区域而不是全屏。

可以。整个文件夹拷到 U 盘，换任何 Windows 电脑都能用，不限设备。
